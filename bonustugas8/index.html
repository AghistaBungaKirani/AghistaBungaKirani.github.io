Pada kode tersebut akan terjadi konflik antar extension karena ada dua extension pada tipe String yang memiliki nama method sama yaitu toInt(). Dart menjadi bingung saat angka.toInt() dipanggil karena tidak tahu harus menggunakan method dari StringNumber atau StringDouble. Walaupun return type berbeda (int dan double), Dart tetap menganggapnya konflik karena return type tidak digunakan untuk membedakan method. Akibatnya program menghasilkan error seperti “The method 'toInt' is defined in multiple extensions”. Agar tidak konflik, nama method harus dibedakan atau extension dipanggil secara langsung menggunakan nama extension.

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

extension StringNumber on String {
  int toIntValue() {
    return int.parse(this);
  }
}

extension StringDouble on String {
  double toDoubleValue() {
    return double.parse(this);
  }
}

void main() {
  String angka = '123';

  print(angka.toIntValue());
  print(angka.toDoubleValue());
}

₊˚⊹♡ Bonus 2 ♡⊹˚₊

Kode tersebut gagal dikompilasi karena extension CounterStats mencoba mengakses member private _value dari class Counter. Dalam Dart, member yang diawali tanda _ bersifat private dan hanya bisa diakses di dalam library/class tertentu. Akibatnya baris return _value; menimbulkan error karena extension tidak memiliki akses langsung ke member private tersebut. Agar tetap bisa mengambil nilai _value tanpa mengubahnya menjadi public, solusi yang benar adalah membuat getter public di dalam class Counter, lalu extension memanggil getter tersebut.

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

class Counter {
  int _value = 0; // private

  void increment() {
    _value++;
  }

  // getter public
  int get value => _value;
}

extension CounterStats on Counter {
  int getValue() {
    return value;
  }
}

void main() {
  var c = Counter();

  c.increment();

  print(c.getValue());
}
