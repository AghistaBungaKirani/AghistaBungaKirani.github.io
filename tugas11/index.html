₊˚⊹♡ Main Constructor dengan Radius ♡⊹˚₊

Main Constructor adalah constructor utama yang digunakan untuk membuat objek Circle dengan memasukkan nilai radius secara langsung. Nilai radius yang diberikan akan disimpan ke dalam atribut radius. 

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

class Circle {
  double radius;

  Circle(this.radius);
}

void main() {
  var circle = Circle(7);

  print("Radius: ${circle.radius}");
}

₊˚⊹♡ Redirecting Constructor dari Diameter ♡⊹˚₊

Redirecting Constructor adalah constructor yang mengarahkan pemanggilan ke constructor lain dalam kelas yang sama. 

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

class Circle {
  double radius;

  Circle(this.radius);

  Circle.fromDiameter(double diameter)
      : this(diameter / 2);
}

void main() {
  var circle = Circle.fromDiameter(14);

  print("Radius: ${circle.radius}");
}

₊˚⊹♡ Redirecting Constructor dari Keliling ♡⊹˚₊

Constructor fromCircumference() menerima nilai keliling lingkaran. 

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

import 'dart:math';

class Circle {
  double radius;

  Circle(this.radius);

  Circle.fromCircumference(double circumference)
      : this(circumference / (2 * pi));
}

void main() {
  var circle = Circle.fromCircumference(43.98);

  print("Radius: ${circle.radius.toStringAsFixed(2)}");
}

₊˚⊹♡ Redirecting Constructor dari Luas ♡⊹˚₊

Constructor fromArea() menerima nilai luas lingkaran. 

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

import 'dart:math';

class Circle {
  double radius;

  Circle(this.radius);

  Circle.fromArea(double area)
      : this(sqrt(area / pi));
}

void main() {
  var circle = Circle.fromArea(153.94);

  print("Radius: ${circle.radius.toStringAsFixed(2)}");
}

₊˚⊹♡ Ringkasan ♡⊹˚₊

  • Redirecting Constructor Menggunakan : this(...) : Redirecting Constructor adalah constructor yang digunakan untuk memanggil constructor lain dalam class yang sama dengan menggunakan sintaks : this(...).
  • Memanggil Constructor Lain dalam Class yang Sama : Fungsi utama Redirecting Constructor adalah untuk meneruskan proses pembuatan objek ke constructor lain sehingga semua inisialisasi dapat dilakukan melalui satu constructor utama.
  • Mengurangi Duplikasi Kode : Penggunaan Redirecting Constructor dapat mengurangi duplikasi kode karena proses inisialisasi objek hanya ditulis satu kali pada constructor utama. Constructor lainnya cukup meneruskan parameter yang diperlukan.
  • Tidak Bisa Berisi Logika Kompleks : Redirecting Constructor tidak dapat berisi logika pemrograman yang kompleks seperti percabangan (if), perulangan (for, while), atau perintah lainnya karena hanya berfungsi untuk mengarahkan pemanggilan ke constructor lain.

₊˚⊹♡ Kesimpulan ♡⊹˚₊

Redirecting Constructor merupakan fitur dalam Dart yang digunakan untuk memanggil constructor lain dalam class yang sama menggunakan sintaks : this(...). Fitur ini membantu membuat kode lebih ringkas, mengurangi pengulangan kode, dan memusatkan proses inisialisasi objek pada satu constructor utama. Namun, Redirecting Constructor memiliki keterbatasan karena tidak dapat digunakan untuk menuliskan logika program yang kompleks.
