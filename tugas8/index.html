₊˚⊹♡ Pengantar Extension Methods ♡⊹˚₊

Apa itu? Extension Methods adalah fitur di Dart yang digunakan untuk menambahkan fungsi atau metode baru pada tipe data yang sudah ada, seperti String, int, atau List.

Tanpa modifikasi kode asli Kita tidak perlu mengubah source code bawaan dari class tersebut. Jadi, class asli tetap aman dan tidak diubah.

Tersedia sejak Dart 2.7 Fitur ini mulai diperkenalkan pada versi Dart 2.7 untuk mempermudah pengembangan program.

Analogi Extension Methods seperti memberi kemampuan tambahan pada sebuah benda tanpa mengubah bentuk aslinya. Contohnya seperti menambahkan aksesoris pada HP agar punya fungsi baru, tetapi HP aslinya tetap sama.

₊˚⊹♡ Masalah Tanpa Extension Methods ♡⊹˚₊

Slide ini menjelaskan bagaimana programmer biasanya menambahkan fungsi pada String sebelum adanya Extension Methods di Dart. Program membuat class bantuan bernama StringUtils yang berisi method capitalize() dan isEmail().

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

// Utility class yang kurang natural
class StringUtils {
  static String capitalize(String text) {
    if (text.isEmpty) return text;
    return text[0].toUpperCase() + text.substring(1);
  }

  static bool isEmail(String text) {
    return text.contains('@');
  }
}

void main() {
  // Penggunaan kurang natural
  var name = 'tata';

  var capitalized = StringUtils.capitalize(name); // 'Tata'
  var isEmail = StringUtils.isEmail('test@mail.com');

  // Cetak variabel name, capitalized, dan isEmail
  print('Original name: $name');
  print('Capitalized name: $capitalized');
  print('Is "test@mail.com" an email? $isEmail');
}

₊˚⊹♡ Solusi dengan Extension Methods ♡⊹˚₊

Slide ini menjelaskan tentang Extension Methods pada bahasa pemrograman Dart. Extension Method digunakan untuk menambahkan fungsi baru ke tipe data yang sudah ada, seperti String, tanpa harus mengubah class aslinya. Pada kode di slide, dibuat extension bernama StringExtensions untuk tipe data String.

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

// Extension method untuk String
extension StringExtensions on String {
  String capitalize() {
    if (isEmpty) return this;
    return this[0].toUpperCase() + substring(1);
  }

  bool get isEmail => contains('@');

  String reverse() {
    return split('').reversed.join();
  }
}

void main() {
  // Penggunaan lebih natural
  var name = 'tata';
  var capitalized = name.capitalize(); // 'Tata'
  var isEmail = 'test@mail.com'.isEmail; // true
  var reversed = 'hello'.reverse(); // 'olleh'

  // Cetak variabel
  print('Original name: $name');
  print('Capitalized name: $capitalized');
  print('Is "test@mail.com" an email? $isEmail');
  print('Reversed "hello": $reversed');
}

₊˚⊹♡ Sintaks Extension Methods ♡⊹˚₊

Slide ini menjelaskan tentang sintaks dasar Extension Methods di Dart. Extension Method digunakan untuk menambahkan fitur baru pada class atau tipe data yang sudah ada tanpa mengubah source code aslinya. 

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

// Sintaks dasar Extension Method
extension DateTimeExtensions on DateTime {

  // Method
  String toFormattedString() {
    return '$day/$month/$year';
  }

  // Getter
  bool get isToday {
    var now = DateTime.now();

    return year == now.year &&
        month == now.month &&
        day == now.day;
  }

  // Operator
  DateTime operator +(Duration duration) {
    return add(duration);
  }
}

void main() {

  // Membuat object DateTime
  var now = DateTime.now();

  // Menggunakan method
  print('Formatted Date: ${now.toFormattedString()}');

  // Menggunakan getter
  print('Is today? ${now.isToday}');

  // Menggunakan operator
  var nextWeek = now + Duration(days: 7);

  print('7 days later: ${nextWeek.toFormattedString()}');
}

₊˚⊹♡ Tipe yang Bisa Di-extend ♡⊹˚₊

Slide ini menjelaskan bahwa Extension Methods di Dart dapat digunakan pada berbagai jenis tipe data. Dengan extension, programmer bisa menambahkan fungsi baru tanpa mengubah class aslinya.

Beberapa tipe yang dapat di-extend yaitu:

  • Built-in types : Tipe bawaan Dart seperti String, int, double, List, dan Map dapat ditambahkan method atau getter baru agar lebih mudah digunakan.
  • Custom classes : Class buatan sendiri juga bisa menggunakan extension sehingga programmer dapat menambah fitur tambahan tanpa mengedit class utama.
  • Generic types : Tipe generic seperti List dan Map dapat di-extend agar bisa dipakai pada banyak tipe data secara fleksibel.
  • Nullable types : Tipe nullable seperti String? atau int? juga dapat diberi extension untuk menangani data yang mungkin bernilai null.

₊˚⊹♡ Extension untuk Null Safety ♡⊹˚₊

Slide ini menjelaskan penggunaan Extension Methods pada tipe data nullable (String?) untuk membantu menangani nilai null dengan lebih aman dan mudah. Dalam Dart, null safety digunakan agar program terhindar dari error ketika variabel belum memiliki nilai. Dengan extension method, programmer dapat menambahkan fungsi tambahan pada nullable string sehingga pengecekan null menjadi lebih praktis.

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

extension NullableStringExtensions on String? {

  // Safe access untuk nullable string
  String orEmpty() => this ?? '';

  bool get isNullOrEmpty => this == null || this!.isEmpty;

  bool get isNotNullOrEmpty => !isNullOrEmpty;

  String withDefault(String defaultValue) =>
      this ?? defaultValue;
}

void main() {

  // Penggunaan
  String? name;

  print(name.orEmpty());              // ''
  print(name.isNullOrEmpty);          // true
  print(name.isNotNullOrEmpty);       // false
  print(name.withDefault('Guest'));   // 'Guest'

}

₊˚⊹♡ Praktik 1 – Utilities untuk Dart Types ♡⊹˚₊

Slide ini menjelaskan contoh penggunaan Extension Methods pada tipe data num untuk menambahkan fungsi utilitas yang sering digunakan. Dengan extension method, tipe data angka seperti int dan double dapat memiliki method tambahan sehingga kode menjadi lebih praktis dan mudah dibaca.

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

extension NumberExtensions on num {

  // Format ke Rupiah
  String toRupiah() {
    return 'Rp${toStringAsFixed(0).replaceAllMapped(
      RegExp(r'(\d{1,3})(?=(\d{3})+(?!\d))'),
      (match) => '${match[1]}.',
    )}';
  }

  // Cek jika dalam range
  bool isBetween(num min, num max) {
    return this >= min && this <= max;
  }

  // Pangkat
  num power(int exponent) {
    var result = this;

    for (var i = 1; i < exponent; i++) {
      result *= this;
    }

    return result;
  }
}

void main() {

  // Penggunaan
  var price = 1500000;

  print(price.toRupiah());   // Rp1.500.000
  print(5.isBetween(1, 10)); // true
  print(2.power(3));         // 8

}

₊˚⊹♡ Generic Extensions ♡⊹˚₊

Slide ini menjelaskan tentang Generic Extensions pada bahasa pemrograman Dart. Extension digunakan untuk menambahkan fungsi baru ke tipe data yang sudah ada tanpa mengubah class aslinya.

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

// Extension untuk List generic
extension ListExtensions on List {

  // Mengambil data dengan aman
  T? getOrNull(int index) {
    if (index < 0 || index >= length) return null;
    return this[index];
  }

  // Membagi list menjadi beberapa bagian
  List> chunk(int size) {
    var chunks = >[];

    for (var i = 0; i < length; i += size) {
      chunks.add(
        sublist(i, i + size > length ? length : i + size),
      );
    }

    return chunks;
  }

  // Menghapus data duplikat
  List distinct() {
    var result = [];

    for (var item in this) {
      if (!result.contains(item)) {
        result.add(item);
      }
    }

    return result;
  }
}

void main() {

  // Contoh penggunaan chunk
  var numbers = [1, 2, 3, 4, 5, 6, 7];
  print(numbers.chunk(3));

  // Contoh penggunaan distinct
  print([1, 2, 2, 3, 3, 3].distinct());
}

₊˚⊹♡ Extension untuk Custom Classes ♡⊹˚₊

Slide ini menjelaskan tentang Extension untuk Custom Classes pada Dart. Extension digunakan untuk menambahkan method atau property baru pada class buatan sendiri tanpa mengubah class aslinya.

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

class Product {
  final String name;
  final double price;

  Product(this.name, this.price);
}

// Extension untuk formatting double ke Rupiah
extension DoubleRupiahFormatter on double {

  String toRupiah() {

    // Convert value to int
    final intValue = toInt();

    // Convert to string
    String numberString = intValue.toString();

    // Add thousands separator
    String formattedString = '';
    int counter = 0;

    for (int i = numberString.length - 1; i >= 0; i--) {
      formattedString = numberString[i] + formattedString;
      counter++;

      if (counter % 3 == 0 && i != 0) {
        formattedString = '.' + formattedString;
      }
    }

    return 'Rp$formattedString';
  }
}

// Extension untuk Product
extension ProductExtensions on Product {

  // Method untuk diskon
  Product withDiscount(double percentage) {
    var discountedPrice = price * (1 - percentage / 100);
    return Product(name, discountedPrice);
  }

  // Format untuk display
  String get displayInfo => '$name - ${price.toRupiah()}';

  // Cek jika mahal
  bool get isExpensive => price > 100000;
}

void main() {

  // Penggunaan
  var laptop = Product('Laptop', 15000000);

  var discounted = laptop.withDiscount(10);

  print(discounted.displayInfo);
  print(laptop.isExpensive);

  var keyboard = Product('Keyboard', 75000);

  print(keyboard.displayInfo);
  print(keyboard.isExpensive);
}

₊˚⊹♡ Praktik 2 – Validator Extensions ♡⊹˚₊

Slide ini membahas tentang Validator Extensions pada bahasa pemrograman Dart. Extension digunakan untuk menambahkan fungsi baru pada tipe data yang sudah ada seperti String dan int tanpa mengubah class aslinya.

//Nama: Aghista Bunga Kirani
//Nim: 251410027
//Kelas: SI2A

// Validator extensions untuk berbagai tipe
extension StringValidators on String {

  // Validasi email
  bool get isEmail {
    return RegExp(r'^[\w\.-]+@[\w\.-]+\.\w{2,4}$')
        .hasMatch(this);
  }

  // Validasi nomor HP
  bool get isPhoneNumber {
    return RegExp(r'^[0-9]{10,13}$')
        .hasMatch(this);
  }

  // Validasi password kuat
  bool get isStrongPassword {
    return length >= 8 &&
        contains(RegExp(r'[A-Z]')) &&
        contains(RegExp(r'[a-z]')) &&
        contains(RegExp(r'[0-9]'));
  }

  // Validasi URL
  bool get isUrl {
    try {
      Uri.parse(this);
      return true;
    } catch (_) {
      return false;
    }
  }
}

// Extension untuk integer
extension IntValidators on int {

  // Cek usia dewasa
  bool get isAdult => this >= 18;

  // Cek bilangan positif
  bool get isPositive => this > 0;

  // Cek bilangan genap
  bool get isEven => this % 2 == 0;

  // Cek bilangan ganjil
  bool get isOdd => this % 2 != 0;
}

void main() {

  // Penggunaan
  var email = 'test@example.com';
  var age = 25;
  var password = 'Pass1234';

  print(email.isEmail);          // true
  print(age.isAdult);            // true
  print(password.isStrongPassword); // true
  print(10.isEven);              // true
}

₊˚⊹♡ Ringkasan & Best Practices ♡⊹˚₊

Ringkasan:

  • Extension methods: Extension methods digunakan untuk menambahkan fungsi baru pada tipe data yang sudah ada seperti String, int, atau List tanpa mengubah class aslinya. Hal ini membuat kode lebih praktis dan mudah digunakan.
  • Sintaks : Sintaks dasar extension pada Dart menggunakan format extension NamaExtension on TipeData. Sintaks ini menunjukkan bahwa extension dibuat untuk tipe data tertentu.
  • Support : Extension mendukung penambahan berbagai fitur seperti method, getter, setter, dan operator sehingga tipe data dapat memiliki fungsi tambahan sesuai kebutuhan program.
  • Generic extensions : Generic extension memungkinkan extension digunakan pada berbagai tipe data generic, misalnya List. Dengan begitu extension menjadi lebih fleksibel dan dapat dipakai untuk banyak jenis data.

Best Practices:

  • Nama jelas: Gunakan nama extension yang mudah dipahami agar fungsi extension langsung terlihat kegunaannya. Dengan nama yang jelas, kode menjadi lebih mudah dibaca dan dipelajari oleh programmer lain.
  • Group by type : Pisahkan extension berdasarkan tipe data utama, misalnya extension untuk String dipisah dengan extension untuk int. Tujuannya agar struktur file lebih rapi dan mudah dikelola.
  • Avoid overuse : Jangan semua fungsi dijadikan extension. Gunakan extension hanya jika benar-benar membantu menyederhanakan kode dan meningkatkan keterbacaan program.
  • Null safety : Extension harus memperhatikan nilai null agar program tidak mudah error. Penanganan nullable type membuat aplikasi lebih aman dan stabil saat dijalankan.
  • Dokumentasi : Tambahkan komentar atau dokumentasi pada extension, terutama jika digunakan dalam project besar atau oleh banyak programmer. Dokumentasi membantu orang lain memahami fungsi extension dengan lebih cepat.
